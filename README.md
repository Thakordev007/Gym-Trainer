A modern and responsive Gym Trainer website designed to help users manage their fitness journey, explore workout plans, and connect with gym trainer services.

🚀 Features

🏠 Modern Home Page
👤 User Registration & Login
🏋️ Workout Plans
📋 Fitness & Training Information
👨‍🏫 Gym Trainer Services
📱 Fully Responsive Design
🎨 Clean and Attractive UI
🔐 User Authentication

🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Python, Django
Database: SQLite3
